# Rowdy Flaps 🐦🔴

A Flappy Bird clone starring **Rowdy the Roadrunner**, mascot of the **University of Texas at San Antonio (UTSA)**.

## Play

- [Open `index.html`](index.html) in a browser (or double-click it)
- **Click / tap / Space** to flap
- **R** to restart after game over
- High score is saved in your browser (`localStorage`)

No build step, no dependencies — one self-contained HTML file (vanilla JS + canvas).
